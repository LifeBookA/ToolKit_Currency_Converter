## [1.2.0] - ۲۰۲۴-۰۷-۲۹

### 🆕 ویژگی‌های جدید

#### نرخ‌های تاریخی
- کلاس `HistoricalRateManager` برای ذخیره و بازیابی نرخ‌های تاریخی
- تولید نمودار SVG بومی بدون وابستگی به JavaScript
- پشتیبانی از سری‌های زمانی در فایل JSON

#### خروجی‌های پیشرفته
- کلاس `CsvExporter` برای تولید خروجی CSV از تبدیل‌های دسته‌جمعی
- کلاس `PdfReportGenerator` برای تولید گزارش PDF با فرمت‌بندی حرفه‌ای

#### امنیت پیشرفته
- کلاس `ApiSigner` برای امضای دیجیتال درخواست‌های API با HMAC-SHA256
- کلاس `RateLimiter` برای محدود کردن نرخ درخواست‌ها مبتنی بر فایل
- جلوگیری از بن شدن IP به دلیل درخواست‌های بیش از حد

#### حالت Daemon
- کلاس `CurrencyDaemon` برای اجرای پس‌زمینه
- بروزرسانی خودکار نرخ‌ها هر ۱ ساعت (قابل تنظیم)
- بررسی خودکار هشدارهای نرخ
- استفاده از `pcntl_fork` در لینوکس

### 📝 مستندات
- افزودن مستندات معماری پروژه
- راهنمای اجرای تست‌ها
- آموزش ساخت Provider سفارشی

## [1.1.1] - ۲۰۲۴-۰۷-۲۷

### 🆕 ویژگی‌های جدید

#### تبدیل دسته‌جمعی (Batch Conversion)
- کلاس `BatchCurrencyConverter` برای تبدیل چندین مبلغ با یک بار دریافت نرخ
- بهینه‌سازی عملکرد برای عملیات گروهی

#### کش حافظه (Memory Cache)
- کلاس `MemoryCacheManager` برای کش سریع در حافظه
- مناسب برای محیط‌های Production با کارایی بالا

#### لاگینگ PSR-3
- کلاس `SimpleLogger` برای لاگینگ حرفه‌ای
- پشتیبانی از سطوح Debug, Info, Warning, Error
- بدون وابستگی به کتابخانه‌های خارجی

#### چندزبانه (i18n)
- کلاس `Translator` برای پشتیبانی از ۵ زبان
- زبان‌های پشتیبانی‌شده: فارسی، عربی، انگلیسی، فرانسوی، آلمانی
- ترجمه پیام‌ها و خطاها

#### سیستم هشدار نرخ
- کلاس `RateAlert` برای تعریف هشدارهای نرخ
- کلاس `RateAlertManager` برای مدیریت و بررسی هشدارها
- قابلیت تنظیم شرط (بالا/پایین بودن نرخ)

#### رابط خط فرمان (CLI)
- ابزار `currency.php` برای دستورات ترمینال
- دستورات: convert, rate, list, batch, alert
- راهنمای کامل داخلی

#### داشبورد وب
- رابط کاربری وب با PHP خالص
- نمودارهای SVG بومی
- تم تیره/روشن
- بدون وابستگی به فریم‌ورک‌های خارجی

#### ارائه‌دهنده ارزهای دیجیتال
- کلاس `CryptoProvider` برای پشتیبانی از BTC, ETH و ۲۰+ ارز دیجیتال
- دریافت نرخ از APIهای معتبر

## راهنمای نسخه‌دهی

این پروژه از سیستم نسخه‌دهی معنایی (Semantic Versioning) پیروی می‌کند:

- **MAJOR.MINOR.PATCH** (مثلاً 1.2.1)
- **MAJOR**: تغییرات ناسازگار با نسخه‌های قبلی
- **MINOR**: افزودن قابلیت‌های جدید به صورت سازگار
- **PATCH**: رفع باگ و اصلاحات جزئی
